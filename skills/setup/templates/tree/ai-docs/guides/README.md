# Guides

The question this folder answers: *how do we do X here?* It holds the standing how-tos for the agent and the owner,
the reusable prompts for subagents and the project's reference lists; a guide is kept true, not dated, so a document
with a date in its name belongs in `findings/` or the handoff's log instead.
