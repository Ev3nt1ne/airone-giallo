# Design notes

The question this folder answers: *what did we decide, and why?* It holds the studies and decisions in their argued
form, with the options weighed, before or beside the specification; what the decision settles is written into the
specification{{#graph_on}}, and a decision something technical rests on also becomes a node of the graph{{/graph_on}}.
