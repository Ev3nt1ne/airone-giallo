# Sources

Downloaded third-party material, each file under its own licence. The files in this folder are git-ignored; this
manifest is committed, one row per file, and a document cites the URL, never the path here. *A path into an ignored
folder is a dead link to every other reader, and committed bytes carry their licence with them.* The hash is
`sha256sum <file>`, so a later download can be compared with the one cited.
